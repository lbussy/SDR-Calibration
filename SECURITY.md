# Security policy

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public issue before a private
reporting channel is published for this repository. Until then, contact the
repository owner privately through the hosting platform.

Include the affected version or revision, operating system, device or driver
when relevant, reproduction steps, impact, and any proposed mitigation.

## Supported versions

No released application versions exist yet. A supported-version table will be
published with the first release.

## Sensitive material

Calibration profiles and evidence bundles must not contain credentials,
authentication tokens, private keys, unrelated device identifiers, or
unnecessary personal information. Test fixtures must use synthetic or reviewed
data.
